## 本轮改动（进 4.0.1）

### 准确性

- 菜单栏与总览共用 `HealthMonitor.evaluate`：SMART/自检走 `HealthPolicy`，温度只走 `HealthPredictor` dwell。不再一边立刻橙、一边写「一切正常」。
- 缺温度不再写成 `0`，也不 `ingest` 成 0°C（避免假恢复、历史尖刺）。
- `SmartParse.dataUnitsToTB`：无 `[N TB]` 时按 NVMe Data Units 换算，禁止把裸计数当 TB。
- ATA 寿命用 Normalized VALUE，不用 Wear_Leveling RAW。
- ATA 只有不可纠正错误进 `mediaErrors`；重分配/pending 不再终身 danger。
- NVMe Critical Warning bit3（只读）→ danger。
- `verifyVolume` 的 `.warning` 不再升 danger。
- 链路 `isDegraded` 不再用「PCI-Express = Gen4×4」误报 Gen3。
- IO 卡片用折线最后一个点，不再取两点 max。
- DownSampler 不再把 Comp. Temp Time 字段改写成温度 min/max。

### 性能

- SMART / IO 按 `wholeDiskBSD` 采，同一物理盘多卷只采一次。
- `DiskCaptureService` TTL 4s → 15s；原生 SMART 成功则跳过 `diskutil info`。
- `smartctl` 最少 30s 一次，2.5s 超时。
- `SmartSnapshot` 约 60s 落盘；`TemperatureSample` 仍按轮询写。

### 测试

新增 `SmartParse.swift` / `SmartParseTests.swift`，以及 HealthPolicy 的 bit3 / 缺温用例。

## 怎么验 4.0.1

1. 打开 `dist/v4/diskmon.app`（不要动 `dist/kept/4.0.0/`）。
2. 插一块外接盘：菜单栏颜色和总览分数应一致。
3. 空闲 1–2 分钟：`smartctl` / `diskutil info` 不应再 5 秒一轮。
4. 缺 SMART 的 USB 桥仍显示 —，不要出现 0°C。
